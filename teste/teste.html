Como conectar as páginas ao PHP

O HTML exibe a interface. O JavaScript envia as requisições. O PHP consulta e atualiza o banco de dados.

1. Organize os arquivos e execute o servidor

sistema-acervo/
├── index.html
├── cadastrar.html
├── editar.html
├── lista.html
├── css/
│   └── style.css
├── php/
│   ├── conexao.php
│   ├── listar.php
│   ├── obter.php
│   ├── cadastrar.php
│   └── editar.php
└── database/
    └── banco.sql

Com o XAMPP, coloque a pasta em htdocs e inicie o Apache e o MySQL. Acesse:

http://localhost/sistema-acervo/index.html

Não abra as páginas por duplo clique nem use apenas o Live Server: o PHP precisa de um servidor compatível.

2. Crie o banco de dados

Execute este SQL no phpMyAdmin. Você também pode salvá-lo em database/banco.sql.

CREATE DATABASE IF NOT EXISTS livraria
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE livraria;

CREATE TABLE livros (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  titulo VARCHAR(150) NOT NULL,
  autor VARCHAR(120) NOT NULL,
  categoria VARCHAR(50) NOT NULL,
  quantidade INT UNSIGNED NOT NULL DEFAULT 0,
  preco DECIMAL(10,2) NOT NULL
);

3. Conecte o PHP ao MySQL

Crie php/conexao.php. Todos os outros arquivos PHP vão reutilizar essa conexão.

<?php
// php/conexao.php
header('Content-Type: application/json; charset=utf-8');

function responder(array $dados, int $status = 200): never {
    http_response_code($status);
    echo json_encode($dados, JSON_UNESCAPED_UNICODE);
    exit;
}

try {
    $pdo = new PDO(
        'mysql:host=localhost;dbname=livraria;charset=utf8mb4',
        'root',
        '', // Senha padrão em algumas instalações locais do XAMPP.
        [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            PDO::ATTR_EMULATE_PREPARES => false
        ]
    );
} catch (PDOException $erro) {
    error_log($erro->getMessage());
    responder(['mensagem' => 'Erro ao conectar ao banco.'], 500);
}

set_exception_handler(function (Throwable $erro) {
    error_log($erro->getMessage());
    responder(['mensagem' => 'Erro interno do servidor.'], 500);
});

Os exemplos usam PHP 8.1 ou superior. Ajuste usuário e senha conforme seu ambiente. Em produção, use credenciais fora do código público e um usuário de banco com permissões limitadas.

4. Liste os livros

Crie php/listar.php. Sua página lista.html já chama esse endereço com Fetch API e espera um array JSON.

<?php
require __DIR__ . '/conexao.php';

if ($_SERVER['REQUEST_METHOD'] !== 'GET') {
    responder(['mensagem' => 'Método não permitido.'], 405);
}

$consulta = $pdo->query(
    'SELECT id, titulo, autor, categoria, quantidade, preco
     FROM livros ORDER BY id DESC'
);

responder($consulta->fetchAll());

A conexão na página acontece neste trecho, que já está no JavaScript de lista.html:

const resposta = await fetch("php/listar.php");
const livros = await resposta.json();

5. Carregue um livro para edição

Crie php/obter.php. O endereço editar.html?id=1 consulta o livro de ID 1.

<?php
require __DIR__ . '/conexao.php';

if ($_SERVER['REQUEST_METHOD'] !== 'GET') {
    responder(['mensagem' => 'Método não permitido.'], 405);
}

$id = filter_var($_GET['id'] ?? null, FILTER_VALIDATE_INT,
    ['options' => ['min_range' => 1]]);

if ($id === false || $id === null) {
    responder(['mensagem' => 'ID inválido.'], 422);
}

$consulta = $pdo->prepare('SELECT * FROM livros WHERE id = :id');
$consulta->execute(['id' => $id]);
$livro = $consulta->fetch();

if (!$livro) {
    responder(['mensagem' => 'Livro não encontrado.'], 404);
}

responder($livro);

O JavaScript de editar.html já utiliza esse endpoint para preencher o formulário.

6. Valide os dados recebidos

Para não repetir a validação, crie mais um arquivo: php/validar.php. Ele será usado no cadastro e na edição.

<?php
// Inclua este arquivo depois de conexao.php.
function validarLivro(): array {
    $titulo = $_POST['titulo'] ?? '';
    $autor = $_POST['autor'] ?? '';
    $categoria = $_POST['categoria'] ?? '';
    $q = $_POST['quantidade'] ?? '';
    $p = $_POST['preco'] ?? '';

    foreach ([$titulo, $autor, $categoria, $q, $p] as $valor) {
        if (!is_string($valor)) {
            responder(['mensagem' => 'Formato de dados inválido.'], 422);
        }
    }

    $titulo = trim($titulo);
    $autor = trim($autor);

    $categorias = [
        'literatura-brasileira', 'ficcao', 'fantasia',
        'educacao', 'desenvolvimento-pessoal', 'outras'
    ];

    $quantidade = filter_var($q, FILTER_VALIDATE_INT,
        ['options' => ['min_range' => 0, 'max_range' => 999999]]);

    // O input type="number" envia o decimal com ponto.
    if ($titulo === '' || mb_strlen($titulo) > 150 ||
        $autor === '' || mb_strlen($autor) > 120 ||
        !in_array($categoria, $categorias, true) ||
        $quantidade === false ||
        !preg_match('/^\d{1,6}(\.\d{1,2})?$/', $p) ||
        (float) $p > 999999) {
        responder(['mensagem' => 'Confira os campos informados.'], 422);
    }

    return [
        'titulo' => $titulo,
        'autor' => $autor,
        'categoria' => $categoria,
        'quantidade' => $quantidade,
        'preco' => $p
    ];
}

Essa validação precisa da extensão mbstring, disponível nas instalações usuais do XAMPP. Validar no navegador não substitui validar no servidor.

7. Salve o cadastro

Crie php/cadastrar.php:

<?php
require __DIR__ . '/conexao.php';
require __DIR__ . '/validar.php';

if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    responder(['mensagem' => 'Método não permitido.'], 405);
}

$dados = validarLivro();

$consulta = $pdo->prepare(
    'INSERT INTO livros (titulo, autor, categoria, quantidade, preco)
     VALUES (:titulo, :autor, :categoria, :quantidade, :preco)'
);
$consulta->execute($dados);

responder([
    'sucesso' => true,
    'id' => $pdo->lastInsertId()
], 201);

Seu formulário de cadastro já aponta para ele:

<form id="formCadastro"
      action="php/cadastrar.php"
      method="post">

Com o envio tradicional, o navegador exibirá o JSON retornado pelo PHP. Para voltar à lista após salvar, substitua o script de cadastrar.html por este:

const formulario = document.getElementById("formCadastro");
const mensagem = document.getElementById("mensagem");
const botao = formulario.querySelector('button[type="submit"]');

formulario.addEventListener("submit", async evento => {
  evento.preventDefault();
  if (!formulario.reportValidity()) return;

  botao.disabled = true;
  mensagem.textContent = "Salvando…";

  try {
    const resposta = await fetch(formulario.action, {
      method: "POST",
      body: new FormData(formulario),
      headers: { Accept: "application/json" }
    });

    const dados = await resposta.json();

    if (!resposta.ok || dados.sucesso !== true) {
      throw new Error(dados.mensagem || "Não foi possível cadastrar.");
    }

    window.location.href = "lista.html";
  } catch (erro) {
    mensagem.textContent = erro.message;
  } finally {
    botao.disabled = false;
  }
});

8. Salve as alterações

Crie php/editar.php. O script de editar.html já envia o formulário para esse arquivo.

<?php
require __DIR__ . '/conexao.php';
require __DIR__ . '/validar.php';

if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    responder(['mensagem' => 'Método não permitido.'], 405);
}

$id = filter_var($_POST['id'] ?? null, FILTER_VALIDATE_INT,
    ['options' => ['min_range' => 1]]);

if ($id === false || $id === null) {
    responder(['mensagem' => 'ID inválido.'], 422);
}

$dados = validarLivro();

$pdo->beginTransaction();

$consulta = $pdo->prepare(
    'SELECT id FROM livros WHERE id = :id FOR UPDATE'
);
$consulta->execute(['id' => $id]);

if (!$consulta->fetch()) {
    $pdo->rollBack();
    responder(['mensagem' => 'Livro não encontrado.'], 404);
}

$dados['id'] = $id;

$consulta = $pdo->prepare(
    'UPDATE livros
     SET titulo = :titulo, autor = :autor,
         categoria = :categoria, quantidade = :quantidade,
         preco = :preco
     WHERE id = :id'
);
$consulta->execute($dados);
$pdo->commit();

responder(['sucesso' => true]);

9. Teste o fluxo completo

  1. Abra cadastrar.html pelo localhost e cadastre um livro.
  2. Confira o registro na tabela livros no phpMyAdmin.
  3. Abra lista.html e pesquise pelo título.
  4. Clique em “Editar”, altere um campo e salve.
  5. Atualize a lista e confira a alteração.

Atualize também os links “Acervo” das outras páginas para lista.html.

Importante: esta integração é uma base para desenvolvimento local, não um painel pronto para publicação. Antes de disponibilizá-la na internet, implemente autenticação, autorização e proteção CSRF. As consultas preparadas ajudam a prevenir SQL Injection, mas não substituem essas proteções.

HTML → requisição HTTP → PHP/PDO → MySQL → resposta JSON → interface.
